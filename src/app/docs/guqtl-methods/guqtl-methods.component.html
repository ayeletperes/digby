Methods

Gene usage QTL

A gene usage QTL (guQTL) scan asks whether genetic variation in an immunoglobulin locus is associated with how much each germline gene is used in the expressed repertoire. This page describes how the scan published here is run, and how to read what it reports. The threshold table is generated from the data currently loaded, not transcribed.

The cohort

Everything on these pages comes from one study: project P28. The scan was run on its genotypes and its repertoires, and every count, frequency and p-value reported anywhere in the guQTL dashboard is that project's. Nothing is pooled across studies, and a genotype count here is not a population frequency; for that, follow a variant's dbSNP link.

The subject totals differ by locus, because a subject enters a locus's scan only if it passes that locus's own filters: 123 for IGH, 156 for IGK and 141 for IGL. Each locus's threshold is derived from its own independent variant count, so the loci are not directly comparable to each other either.

When more studies are loaded this section will have to say something else. It is written to be wrong in an obvious way rather than to quietly go stale.

The phenotype

The phenotype is a usage fraction: for each subject and each allele similarity cluster (ASC), the share of rearrangements assigned to that cluster. It is computed with a smoothing term,

usage = (count + 0.5) / (total + 0.5 × n_asc)

where count is the subject's rearrangements assigned to the ASC, total the subject's rearrangements in the same segment, and n_asc the number of clusters in that segment. The added constant keeps a cluster a subject never uses from sitting exactly at zero.

Three properties of this quantity matter when interpreting a result:

  • Only productive rearrangements contribute, and only those with v_mut ≤ 0. Restricting to unmutated rearrangements enriches for antigen-naive B cells, so the phenotype reflects germline usage rather than the clonal expansion of a responding population.
  • A cluster's usage is a share of its own segment, not of the locus. V cluster usages sum across V, J cluster usages across J. A V and a J usage are not fractions of the same denominator and should not be compared as though they were.
  • The logit transform is applied for modelling only. The usage value stored and displayed throughout the site is the untransformed fraction defined above.

One scan per cluster

Each ASC is its own scan. For a given cluster, the transformed usage is regressed on variant dosage by ordinary least squares, with dosage as the only predictor and no covariates.

A p-value therefore belongs to one (variant, ASC) pair. It is evidence about that variant's association with that one cluster's usage. Two p-values from different clusters come from separate regressions on separate phenotypes; ranking variants across clusters compares separate experiments rather than competing explanations of one signal.

Significance threshold

The threshold is

threshold = 0.05 / n_independent

applied per ASC. It is not divided again by the number of clusters. Because each cluster is a separate scan of the same variant set, the correction covers the variants within one scan.

n_independent is not the number of variants tested. It is the number remaining after variants in complete linkage disequilibrium are collapsed, where complete LD means identical standardised dosage up to sign: such variants partition the subjects into exactly the same groups and cannot yield different results, so counting them separately would correct for tests that carry no independent information. The n_variants and n_independent columns below show the size of that reduction.

This collapse is distinct from clumping. Clumping groups correlated variants at r² ≥ 0.80 to form reporting leads, so that a single association is presented once rather than once per correlated variant. It shapes what is displayed; the complete-LD collapse sets the threshold. They use different criteria and are not interchangeable.

Genotype group sizes

min_genotype_group is the number of subjects in the smallest genotype class of a variant. It is reported alongside every association because the parametric p-values are documented as anti-conservative in the extreme tail: the usage phenotypes are heavy-tailed, and when one genotype class is small a single outlying subject in it can inflate the t statistic. The smaller this count, the less the extreme tail of the p-value can be taken at face value.

It is a reporting flag, not a filter. Associations resting on a small genotype class are retained and marked, not removed. A p-value from this scan should never be presented without its min_genotype_group.

Coordinate frames

Positions are reported in the frame of the locus that was scanned, and the frames differ between loci:

  • IGH is on a locus-relative contig named literally igh. Its coordinates are offsets within that contig and are not chromosome 14 coordinates.
  • IGK is on chromosome 2.
  • IGL is on chromosome 22.

A position is meaningful only within its own locus. Positions must not be compared between loci, and an IGH position in particular will not resolve against a chromosome 14 assembly without translation.

What the scan does not do

  • No fine-mapping. The scan reports associated variants. It does not attempt to resolve which variant in an associated region is responsible.
  • No causal claim. LD blocks in these loci reach 40 kb, so an associated variant is generally one of many that are indistinguishable on this data. An association marks a region, not a mechanism.
  • No ancestry adjustment in the primary scan. Dosage is the only predictor and no ancestry covariates are fitted, so population structure is not controlled for.
